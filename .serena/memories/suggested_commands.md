# Suggested Commands

- Install deps: `npm ci`.
- Build package: `npm run build`.
- Watch build: `npm run dev`.
- Test + type tests: `npm test` or `npm run test`.
- Typecheck only: `npm run typecheck`.
- Lint: `npm run lint`.
- Format/lint fix: `npm run lint:fix`.
- Windows file search: prefer `rg --files` and `rg "pattern"`; shell is PowerShell.
- Git status: `git status --short` before edits because user changes may be present.
