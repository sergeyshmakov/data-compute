## `Graph<T>`

A computation graph parameterized by its root state type.

```ts
interface Graph<T> {
  compute(patch: DeepPartial<T>): Promise<DeepPartial<T>>;

  // Inspection
  readonly nodes: readonly Path[];
  readonly sources: readonly Path[];
  readonly order: readonly Path[];
  deps(accessor: Accessor<T>): readonly Path[];
  dependents(accessor: Accessor<T>): readonly Path[];
  toMermaid(): string;

  // Status
  computeStatus(accessor: Accessor<T>): NodeStatus;
  computeResult<U>(accessor: Accessor<T, U>): NodeResult<U>;
  status(key: string): NodeStatus;
  snapshot(key: string): NodeResult<unknown>;

  // Debugging
  trace(input: DeepPartial<T>): TraceEntry[];
}
```

## `NodeStatus`

```ts
type NodeStatus = "ready" | "pending" | "stale" | "error";
```

| Status | Meaning |
|---|---|
| `"ready"` | The node has a computed value as of the current cycle. |
| `"pending"` | The node or one of its dependencies is awaiting an async resolution. |
| `"stale"` | The node's last result was invalidated by an input change before completion. |
| `"error"` | The node's formula or data source threw. |

## `NodeResult<U>`

```ts
interface NodeResult<U> {
  value: U | undefined;
  status: NodeStatus;
  error?: unknown;
}
```

## `DataSource<T, U>`

The shape returned by `request` and `batchRequest`. You don't typically construct these directly — use the helpers.

```ts
type DataSource<T, U> = {
  readonly deps: (state: T) => unknown;
  readonly query: (input: unknown) => Promise<U> | Promise<U[]>;
  readonly stalePolicy?: "discard" | "discard-and-retry";
};
```

## `DeepPartial<T>`

The shape of a `compute()` input and output patch. Recursively makes every property optional, preserving nested object structure.

```ts
type DeepPartial<T> = T extends object
  ? { [K in keyof T]?: DeepPartial<T[K]> }
  : T;
```

Use this when typing your own helpers that wrap `compute()`:

```ts
function applyOrderUpdate(patch: DeepPartial<OrderForm>) {
  return graph.compute(patch);
}
```

## `Accessor<T, U = unknown>`

A lambda that extracts a node path from the root state. Used by `deps`, `dependents`, `computeStatus`, and `computeResult`.

```ts
type Accessor<T, U = unknown> = (state: T) => U;

graph.computeStatus((f) => f.subtotal);  // status of subtotal node
graph.deps((f) => f.tax);                // direct deps of tax
```

The function is never invoked with real state — it's evaluated against a recording Proxy, the same engine as [`data-path`](https://www.npmjs.com/package/data-path).

## Inference notes

- `createGraph<T>(formulas)` — formula return types are checked against the declared `T[K]` for each computed field.
- Source fields are inferred from `T` minus the keys present in `formulas` and `dataSources`.
- `compute()`'s return promise resolves to a `DeepPartial<T>` — TypeScript will narrow it based on what fields were actually written this cycle if you destructure.
